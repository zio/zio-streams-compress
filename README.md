# ZIO Streams Compress

[ZIO Streams Compress](https://github.com/zio/zio-streams-compress) integrates several compression algorithms and archive formats with [ZIO Streams](https://zio.dev). Every codec and archive format is a pipeline, so it fits into a stream with `ZStream#via` like any other operator.

## Installation

The library is published for Scala 3, 2.13 and 2.12, and runs on the JVM only. Scala.js and Scala Native are not supported; PRs for them are welcome. As of 2.1.3, it requires ZIO 2.1.25 or later.

The `core` module holds the shared interfaces. Every codec and archive module in [Modules](#modules) depends on it and pulls it in, so you rarely add it on its own:

```sbt
// zio-streams-compress-core: Compressor, Decompressor, Archiver, Unarchiver and ArchiveEntry interfaces
libraryDependencies += "dev.zio" %% "zio-streams-compress-core" % "3.0.1"
```

## Modules

Each format lives in its own module, so a project only pulls in the third-party libraries of the formats it uses. Add the modules you need.

### Compression Codecs

A codec compresses or decompresses one stream of bytes:

```sbt
// zio-streams-compress-gzip: Gzip compressor and decompressor, built on the JDK
libraryDependencies += "dev.zio" %% "zio-streams-compress-gzip" % "3.0.1"

// zio-streams-compress-zstd: Zstandard compressor and decompressor, built on zstd-jni (native)
libraryDependencies += "dev.zio" %% "zio-streams-compress-zstd" % "3.0.1"

// zio-streams-compress-brotli: Brotli decompressor only, built on the pure-Java Brotli decoder
libraryDependencies += "dev.zio" %% "zio-streams-compress-brotli" % "3.0.1"

// zio-streams-compress-brotli4j: Brotli compressor and decompressor, built on Brotli4J (native)
libraryDependencies += "dev.zio" %% "zio-streams-compress-brotli4j" % "3.0.1"

// zio-streams-compress-bzip2: Bzip2 compressor and decompressor, built on Apache Commons Compress
libraryDependencies += "dev.zio" %% "zio-streams-compress-bzip2" % "3.0.1"

// zio-streams-compress-lz4: LZ4 frame compressor and decompressor, built on lz4-java
libraryDependencies += "dev.zio" %% "zio-streams-compress-lz4" % "3.0.1"

// zio-streams-compress-snappy: Snappy compressor and decompressor (framed and basic formats; Hadoop format write-only), built on snappy-java
libraryDependencies += "dev.zio" %% "zio-streams-compress-snappy" % "3.0.1"
```

Each codec has a reference page: [Gzip](docs/./reference-gzip.md), [Zstd](docs/./reference-zstd.md), [Brotli](docs/./reference-brotli.md), [Brotli4J](docs/./reference-brotli4j.md), [Bzip2](docs/./reference-bzip2.md), [LZ4](docs/./reference-lz4.md) and [Snappy](docs/./reference-snappy.md). [Choosing a Codec or Archive Format](docs/./choosing-a-codec.md) compares them.

### Archive Formats

An archive format bundles many named entries into one stream of bytes:

```sbt
// zio-streams-compress-zip: ZIP archiver and unarchiver, built on the JDK; entry sizes may be unknown
libraryDependencies += "dev.zio" %% "zio-streams-compress-zip" % "3.0.1"

// zio-streams-compress-zip4j: ZIP archiver and unarchiver with password protection (ZIP standard and AES), built on Zip4J
libraryDependencies += "dev.zio" %% "zio-streams-compress-zip4j" % "3.0.1"

// zio-streams-compress-tar: Tar archiver and unarchiver, built on Apache Commons Compress
libraryDependencies += "dev.zio" %% "zio-streams-compress-tar" % "3.0.1"
```

Each archive format has a reference page: [Zip](docs/./reference-zip.md), [Zip4J](docs/./reference-zip4j.md) and [Tar](docs/./reference-tar.md).

## Example

The example below compresses a file with Gzip, lists the entries of a Tar archive compressed with Gzip, and creates a ZIP archive:

```scala
import zio._
import zio.compress._
import zio.stream._

object ExampleApp extends ZIOAppDefault {
  override def run: ZIO[Any, Any, Any] =
    for {
      // Compress a file with Gzip
      _ <- ZStream
             .fromFileName("file")
             .via(GzipCompressor.compress)
             .run(ZSink.fromFileName("file.gz"))

      // List all items in a gzipped tar archive
      _ <- ZStream
             .fromFileName("file.tgz")
             .via(GzipDecompressor.decompress)
             .via(TarUnarchiver().list)
             .mapZIO { entry =>
               Console.printLine(s"${entry.name} ${entry.uncompressedSize.getOrElse(-1L)}")
             }
             .runDrain

      // Create a ZIP archive with one entry
      _ <- ZStream(entry("file1.txt", "Hello world!".getBytes("UTF-8")))
             .via(ZipArchiver().archive)
             .run(ZSink.fromFileName("file.zip"))
    } yield ()

  private def entry(
    name: String,
    content: Array[Byte],
  ): (ArchiveEntry[Option, Any], ZStream[Any, Throwable, Byte]) =
    (ArchiveEntry[Option, Any](name), ZStream.fromIterable(content))
}
```

When you read an archive with `Unarchiver#unarchive`, read each entry's content completely before the next entry is emitted, or the pipeline locks up. [How Unarchiving Streams Entries](docs/./streaming-unarchiving.md) explains why.
